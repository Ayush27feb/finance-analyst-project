💰 Finance Analytics Project 

📌 Project Overview
An end-to-end Finance Analytics project built using Excel, SQL, and Power BI to analyze financial transactions, customer behavior, transaction trends, and business performance.
The project demonstrates the complete data analytics workflow, from data cleaning and SQL analysis to interactive dashboard development in Power BI.

🎯 Business Objectives

- Analyze financial transaction trends over time
- Identify high-performing transaction types and channels
- Analyze customer transaction behavior
- Identify major merchant categories
- Analyze transaction success and failure patterns
- Monitor fraud indicators and risk levels
- Generate actionable business insights from financial data

🛠️ Tools & Technologies

- Excel – Data cleaning and preprocessing
- SQL – Data analysis, joins, subqueries, aggregations, and business queries
- Power BI – Data modeling, DAX, KPIs, and interactive visualization

📂 Dataset
The project contains two main datasets:

- `finance_customers.csv` – Customer information
- `finance_transactions.csv` – Financial transaction data
